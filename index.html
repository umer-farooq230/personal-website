Featured Project
Regime Switching Engine for Financial Time Series
Python · ARIMA · GARCH · statsmodels · arch · Streamlit

A forecasting system that partitions financial time series into 30-day windows and routes each window to either ARIMA or GARCH based on a volatility test. Instead of applying a single model across all market conditions, this engine adapts to the regime the market is currently in.

RMSE 0.0097 (adaptive)    -4.3% vs GARCH-only    2233 windows processed
